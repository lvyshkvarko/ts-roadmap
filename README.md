# Роадмап TechSupport (Jira) на GitHub Pages

В архиве два файла сайта:
- `index.html` — сам сайт;
- `data.json` — задачи из Jira на 5 ноября.

Пароля нет: сайт открывается сразу по ссылке. Имейте в виду, что адрес и файл `data.json` видны всем, кто знает ссылку.
Почты игроков из описаний и комментариев при публикации заменяются на «[почта скрыта]».

---

## Часть 1. Разместить сайт (один раз, ~10 минут)

1. **Аккаунт.** Зарегистрируйтесь на https://github.com (Sign up) и подтвердите почту.
   Ваш логин станет частью адреса сайта.
2. **Репозиторий.** Справа вверху нажмите «+» → **New repository**.
   - Repository name: `ts-roadmap`
   - Видимость: **Public** (бесплатный GitHub Pages работает только с публичными репозиториями)
   - Нажмите **Create repository**.
3. **Загрузить файлы.** На странице нового репозитория нажмите ссылку **uploading an existing file**.
   Распакуйте архив, перетащите в окно `index.html` и `data.json` и внизу нажмите **Commit changes**.
4. **Включить сайт.** В репозитории откройте вкладку **Settings** → слева **Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
5. Подождите 1–2 минуты и обновите страницу Settings → Pages. Вверху появится
   «Your site is live at **https://ЛОГИН.github.io/ts-roadmap/**». Это и есть ссылка на сайт.

---

## Часть 2. Токен для публикации (один раз)

Токен нужен, чтобы сайт сам заливал новые данные на GitHub.

1. github.com → ваша аватарка справа вверху → **Settings** → в самом низу слева **Developer settings**
   → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Заполните:
   - Token name: `roadmap`
   - Expiration: например, 90 дней (когда истечёт, просто сделайте новый)
   - Repository access: **Only select repositories** → выберите `ts-roadmap`
   - Permissions → Repository permissions → **Contents: Read and write**
3. Нажмите **Generate token** и **скопируйте токен сразу**: GitHub показывает его один раз.
4. На сайте нажмите **⟳ Обновить** → раскройте «Настройки GitHub» → вставьте токен.
   Логин и репозиторий подставятся сами.

Токен хранится только в вашем браузере. Никому его не отправляйте.

---

## Часть 3. Обновлять данные (каждый раз)

1. Включите **VPN** и откройте любую страницу jira.blackhub.team.
2. Нажмите закладку **⟳ Sync CS-409** → **Скопировать**.
   Закладку можно один раз перетащить на панель закладок из окна «⟳ Обновить» на сайте.
3. Откройте сайт → **⟳ Обновить** → вставьте данные (Ctrl+V) → **Опубликовать**.
4. Через 1–2 минуты обновление увидят все.

Без токена: кнопка **«Только скачать файл»** сохранит `data.json`.
Загрузите его в репозиторий через **Add file → Upload files** с заменой старого.

---

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| «GitHub не принял токен (401)» | Токен истёк или скопирован не целиком — создайте новый (Часть 2). |
| «Токену не хватает прав (403)» | В настройках токена нужно Contents: **Read and write** именно на этот репозиторий. |
| «Репозиторий не найден (404)» | Проверьте логин и название репозитория в «Настройках GitHub». |
| Сайт показывает старые данные | Подождите 2–3 минуты и обновите страницу (Ctrl+F5). |
